2. Partition Theory Foundations

[ \sum_i p_i = N ]

A sub‑partition (Q \subseteq P) satisfies:

[ \sum_j q_j < N ]

A residue is defined as:

[ R = P \ominus Q ]

Phoenix uses partitions to represent structural decomposition.

4.3 Reversibility Invariant

[ \lambda(\gamma(P)) = P ]
