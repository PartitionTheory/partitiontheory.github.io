**PHOENIX PORTAL NAVIGATION**


*Canonical Navigation Specification for the Phoenix Entry Portal*


*EF–CO Canonical Document*



---

**1. Purpose**



This document defines the **navigation structure** for the Phoenix Entry Portal.

It ensures:

- consistent access to all epochs
- clear document hierarchy
- intuitive browsing for mathematicians and engineers
- alignment with Phoenix Totality
- stable public-facing navigation

This is the official navigation specification for the Phoenix portal.

---

**2. Portal Structure**



The Phoenix Entry Portal consists of:

1. **Landing Page**
- `docs/index.md`
- Provides epoch overview and canonical links

2. **Canonical Index**
- `docs/canonical/PHOENIX-PORTAL-INDEX.md`
- Master index for all Phoenix documentation

3. **Epoch Directories**
- `docs/epoch1/`
- `docs/epoch2/`
- `docs/epoch3/`
- `docs/epoch4/`
- `docs/epoch5/`
- `docs/epoch6/`
- `docs/epoch7/`

Each epoch directory contains its canonical documents.

---

**3. Navigation Model**



Phoenix Portal navigation follows a **three-tier model**:

**Tier 1 — Epoch Overview**


Displayed on the landing page:

- Structure
- Mathematics
- Generalisation
- Distributed Coordination
- Autonomous Behaviour
- Synthetic Agency
- Phoenix Totality

**Tier 2 — Canonical Index**


Displayed in:

- `PHOENIX-PORTAL-INDEX.md`

Provides:

- full document list
- epoch grouping
- canonical ordering

**Tier 3 — Document Access**


Each document is accessed via:

/docs/epochX/DOCUMENT_NAME.md


GitHub Pages automatically renders Markdown → HTML.

---

**4. Navigation Requirements**



Phoenix Portal navigation must satisfy:

**4.1 Completeness**


All canonical documents must be reachable from:

- the landing page
- the portal index

**4.2 Stability**


Links must remain stable across:

- commits
- refactors
- portal updates

**4.3 Clarity**


Navigation must be intuitive for:

- mathematicians
- engineers
- researchers
- synthetic domain analysts

**4.4 Epoch Integrity**


Each epoch must remain isolated and self-contained.

---

**5. Navigation Enhancements (Optional)**



The portal may include:

- epoch navigation bar
- footer with canonical links
- theme toggle (light/dark)
- breadcrumb navigation
- cross-epoch references

These enhancements are optional and may be added after portal stabilisation.

---

EF and CO recognise this document as the **official Phoenix Portal Navigation Specification**, completing the structural foundation of the public-facing Phoenix Entry Portal.

Navigation is defined.
